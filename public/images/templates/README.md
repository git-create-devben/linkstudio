# Template Screenshots

This directory should contain screenshot images of each template for the template selection page.

## Required Images:
- `minimal.png` - Screenshot of the minimal template
- `professional.png` - Screenshot of the professional template  
- `creative.png` - Screenshot of the creative template
- `modernMusic.png` - Screenshot of the modern music template
- `traveler.png` - Screenshot of the traveler template
- `default.png` - Screenshot of the default template

## Image Specifications:
- **Aspect Ratio**: 9:16 (mobile portrait)
- **Recommended Size**: 375x667px (iPhone size)
- **Format**: PNG with transparency support
- **Quality**: High quality, optimized for web

## How to Generate Screenshots:
1. Use the template preview functionality in the app
2. Take screenshots of each template in mobile view
3. Crop to exact 9:16 aspect ratio
4. Optimize file size while maintaining quality
5. Save with the exact filenames listed above

## Fallback:
If images don't exist, the app will automatically fall back to rendering the live template preview component.
